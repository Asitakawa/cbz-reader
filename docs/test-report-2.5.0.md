## 二、本轮加固（P0）

| 问题 | 处理 | 验证 |
|---|---|---|
| 两个进程同时写书库会互相覆盖 | 改成**强制单实例**：`QLockFile` 抢锁 + `QLocalServer` 接收唤醒请求；第二个进程把已有窗口唤到前台后退出（`--allow-multi` 保留给调试） | 真机双进程：第二实例 **1.0s** 退出并唤醒；回归测试用子进程验证抢锁失败、唤醒到达、释放后可重入 |
| JSON 损坏后静默变空库，下次保存覆盖 | 写入前把「能解析的当前文件」轮换为 `.bak`；读取时主文件失败回退 `.bak`；损坏内容不会顶掉好备份 | 单测覆盖：首写无备份、二次写生成备份、损坏回退、坏文件不覆盖备份、缺失返回默认值 |
| 窗口模式（pythonw）崩溃无任何痕迹 | `data/app.log`（1MB × 3 轮转）+ 全局 `excepthook` + Qt 消息收集；stderr 转发进日志 | 日志已实际捕获过一次启动异常（`Store.recovered` 未初始化），证明链路有效 |
