## 四、本轮修复

### 修复后的导入规则

- 目录**本身**有图片 → 一话（直属图片优先排在前面）
- 目录下每个**含图片（任意深度）的子目录** → 各算一话
- 目录里有 `.cbz` / `.zip` → 每个各算一话
- 隐藏目录 / `__MACOSX` / 非图片文件不参与

已知残留（非缺陷）：若直接把 `第4话`（其图片在 `pages/` 里）拖进来，会成为名为
`pages` 的一话，可在书详情里重命名；从上级目录导入时则正确命名「第4话」。
